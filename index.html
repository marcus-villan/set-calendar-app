Add Set to your Home Screen

  1. Tap the Share button in Safari's toolbar.
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add. Set now opens like any other app.
Heads up: on iPhone, the Home Screen app can keep its sets separately from Safari. If you already added sets here, export a backup first, then use Import backup (Settings) inside the new app.

Open your browser's menu and choose Install app or Add to Home Screen.

If you don't see it, your browser may not support installing web apps.
