Set — Quick Calendar Pins

A simple, fast, and interactive calendar application designed for quick daily planning and event tracking using emoji pins.
"Set" is built to streamline day-to-day scheduling. Instead of filling out complex form fields for every single item, users can quickly tap on any date to attach custom emoji pins and brief event notes, making calendar management visual and effortless.

Technology & Model Used
Frontend: HTML5, Tailwind CSS (v4), Vanilla JavaScript (ES Modules)
Icons & Typography: FontAwesome 6, Google Fonts (Inter)
AI Model: Designed and developed with the assistance of Google Gemini for UI/UX component architecture, responsive Tailwind styling, and application logic.
